This project is a complete game engine programmed in C that allow 2d rendering, 3d rendering, GUI rendering.

Higly configurable on the back technology allow the usage of multiple graphics api (via SDL surface, SDL renderer, Open\+GL context, ...) and to render using CPU or GPU.\hypertarget{md_README_autotoc_md3}{}\doxysection{\texorpdfstring{Built with}{Built with}}\label{md_README_autotoc_md3}
